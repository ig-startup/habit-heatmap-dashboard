# Design System — Habit Heatmap Dashboard

## Принципы

- Тёмная тема — единственная (по референсу "Habits")
- GitHub-style хитмап как центральный визуальный элемент
- Минимум декора: карточка = иконка + хитмап + streak/дни/бейдж

## Цвета

| Токен | HEX | Назначение |
|-------|-----|------------|
| `bg` | `#0d1117` | Фон страницы |
| `surface` | `#161b22` | Карточки |
| `border` | `#21262d` | Границы, пустые ячейки хитмапа |
| `text` | `#e6edf3` | Основной текст |
| `muted` | `#7d8590` | Вторичный текст (streak-число, дни) |
| `accent` | `#3fb950` | Цвет по умолчанию для новой метрики (GitHub-зелёный) |

Каждая метрика может иметь свой `color` (hex) — используется для интенсивности её хитмапа.
Остальная UI-палитра (фон/поверхность/текст) — общая, не зависит от метрики.

### Уровни интенсивности хитмапа

5 уровней, интерполяция alpha-канала цвета метрики относительно значения:

| Уровень | Условие (value / max за год) | Opacity |
|---------|-------------------------------|---------|
| 0 | нет данных / 0 | — (цвет `border`) |
| 1 | ≤ 25% | 0.3 |
| 2 | ≤ 50% | 0.5 |
| 3 | ≤ 75% | 0.75 |
| 4 | > 75% | 1.0 |

## Типографика

- **Space Mono** — заголовок, метки карточек, числа (streak/дни/бейдж), подписи месяцев
- **Space Grotesk** — обычный текст (пока не используется — UI почти весь моноширинный)

Шрифты подключены через Google Fonts (`index.html`).

## Карточки

- `bg-surface`, `border border-border`, `rounded-lg`, `padding: 20px`
- Flex-раскладка: иконка+название → хитмап (скроллится по X на мобильных) → streak/дни/бейдж
- Responsive: на узких экранах карточка становится column (`flex-col sm:flex-row`)

## Хитмап (SVG)

- Ячейка 11×11px, gap 3px, `rx=2` (лёгкое скругление, не полный circle)
- Подписи месяцев сверху, моноширинным шрифтом 10px, цвет `muted`
- Недели — колонки, дни — строки (Sun→Sat), как в GitHub contribution graph

## Чего не делать

- Не делать светлую тему
- Не использовать цвета вне палитры метрики + базовых токенов
- Не добавлять анимации хитмапа (hover — только нативный `<title>`-tooltip)
